# mi-primer-repo

Repositorio de práctica creado en vivo durante el taller **Versiona y comparte tus proyectos de RStudio con GitHub**, impartido en la R & Python Week 2026 de la Sociedad Ecuatoriana de Estadística (SEE) el 10 de octubre de 2026.

Este repositorio no es un proyecto real. Sirvió para mostrar paso a paso cómo trabajar con Git y GitHub desde RStudio.

## Qué se practicó aquí

- Crear un repositorio en GitHub y clonarlo en RStudio
- Hacer commits y ver las diferencias entre versiones
- Subir cambios con push y traer cambios con pull
- Colaborar con fork, rama y pull request ([PR #1](../../pull/1), de [Luis D. Verde Arregoitia](https://github.com/luisDVA))

## Contenido

| Archivo | Descripción |
|---|---|
| `analisis.R` | Script de ejemplo con ventas ficticias por región de Ecuador |
| `ventas.csv` | Datos exportados desde el script |
| `mi-primer-repo.Rproj` | Proyecto de RStudio |
| `.gitignore` | Archivos que Git no debe rastrear |
